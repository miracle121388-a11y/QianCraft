# Workbench surface brief

- Scope / mode: `/`, desktop-first web operating surface; Operate.
- Audience / job: cultural researchers, product strategists and designers inspect evidence, change decisions, run nodes and continue a design chain without losing provenance.
- Primary action: run the current workflow or continue from the selected node.
- Proof / content: 22 verified cultural records, 32 registered sources, a separate human-reviewed candidate queue, 378 bounded historical market samples, eight opportunities, nine node instances, Human Decision profile, A/B/C concepts and the existing modular-magnet visual.
- Constraints: preserve real HTTP data, node actions, workspace persistence, citations, deep links and honest live/cache/stale/warning/degraded/blocked/offline states. A discovered URL never becomes formal cultural knowledge automatically; historical market evidence never becomes live merely because a schedule exists. Do not alter cultural facts or imply production, compliance or commercial-artwork approval.
- Chosen direction: Monochrome Precision Instrument, user-pinned and shipped under seed `a403e052`. White is the working plane, cool neutral gray establishes depth, graphite carries text and pure black marks selection and the sole primary action. Beige, warm-paper and blue/indigo system chrome are excluded. Original product, evidence and concept images may retain source color.
- Structural signature: a 60px white desktop command bar, 56px light-gray tool rail, contextual Dock, dominant node canvas and 336px Inspector. The empty workbench canvas is directly draggable with the primary pointer or one finger; Shift-drag keeps box selection, wheel/pinch keeps zoom and dragging a node moves only that node. Selection changes black contrast and keylines without changing node geometry. Culture detail uses the one deliberate dark exception: a black relationship constellation paired with a white evidence Inspector, search, category filter and view controls. System/SF-like sans type, fine rules, compact semantic radii and restrained overlay shadows keep the surface precise and tool-like rather than promotional.
- Continuous evidence: culture detail separates 22 formal records / 32 sources from pending candidates and exposes scheduler heartbeat, schedule, attempts, successes, partial failures and review history. Market detail puts 378 historical samples, their date window and platform distribution before an expandable live-collection console. Polling or heartbeat failure invalidates stale online state; partial source failure is `degraded`; missing live switch or authorization is `blocked`.
- Input parity: every draggable culture or market record also exposes a visible add-to-canvas button, with a 44px mobile target and Chinese status confirmation. React Flow selection/movement announcements are localized in Chinese.
- Memorable moment: selecting a culture star brightens its path through category and source points while a white evidence Inspector resolves region, craft, boundaries and references without leaving the relation field.
- Approved direction source: direct user instruction and code-led review; there is no external visual comp to reproduce.
- Responsive behavior: at 760px and below, keep a 72×56 current-phase selector, a 44×44 black Run action, a 56px rail and at least 44px for primary buttons, selects, summaries and canvas controls. Dock and Inspector become reversible overlays. The constellation defaults to page-scrolling `pan-y pinch-zoom`; an explicit “操作星图” control enables one-finger pan and two-finger zoom, and “完成” returns control to the page. Collection controls stack to one column and keep reconnect, schedule and candidate actions at least 44px. Workspace and phase popovers remain fully inside the viewport. The Decision Studio keeps black Save as the sole primary action and groups its two secondary actions below it.
- Accessibility behavior: Culture constellation, Workspace and Decision Studio have labelled semantics, visible keyboard focus and reversible focus behavior where modal. Search can focus a sole matching star; arrow keys pan and `+ / - / 0` control the constellation. Reduced motion removes animated travel without erasing static state; increased contrast and forced-colors distinguish the constellation core, ordinary records, selected records, sources and relation paths with system roles.
- Exceptions: the culture constellation is a real relationship work surface and may use a black canvas with white stars and lines. This is an achromatic, task-bound exception; it does not authorize dark marketing surfaces, decorative star fields or grids elsewhere.
- Runtime boundary: the scheduler can operate continuously only while one Tool API/container instance, persistent runtime volume, restart policy, network and required platform authorization stay available. It is not a distributed queue. Local 0.9.0 is not deployed; the protected online instance remains 0.8.0, and the market lane is currently blocked by `MEDIACRAWLER_LIVE_ENABLED=false` plus missing xhs/dy/bili/wb authorization sessions.
- Validation: the 0.8.2 manual audit remains the historical 48-screenshot route/state record in `.impeccable/review/full-audit-082/README.md`. The 0.9.0 gate now records Python 53 passed, frontend unit tests 5 passed and Playwright 35 passed / 1 intentionally skipped across `/` plus all nine node routes at 1440×960 and 390×844. It covers axe A/AA/2.2 AA rules, one `h1`, image integrity, document/main overflow, 44px mobile controls, evidence input parity, Chinese canvas semantics, dialog focus cycles, workbench pointer/keyboard behavior, constellation search/selection/desktop drag/wheel/keyboard/mobile page scroll/one-touch pan/two-touch zoom, disconnected collection state, partial-source degradation, authorization blockers, forced-colors and reviewed screenshots. Typecheck, lint, production build, Ruff, shell syntax, lockfile and diff checks also pass. Automated coverage remains partial and does not constitute WCAG certification.
