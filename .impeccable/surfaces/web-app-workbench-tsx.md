# Workbench surface record

- Scope / mode: `/`, desktop-first evidence workbench in Operate mode. The current C2 implementation and acceptance scope is Windows Chromium at 1440×960 only.
- Audience / job: cultural researchers, product strategists and designers inspect evidence, change decisions, run nodes and continue a design chain without losing provenance.
- Primary action: run the current workflow or continue from the selected node. Each task region keeps one deep desaturated-blue primary action; secondary controls remain light-stone.
- Proof / content: real HTTP data, 22 formal cultural records, 32 registered sources, a separate human-reviewed candidate queue, 378 bounded historical market samples, eight opportunities, nine node instances, ten edges, Human Decision profile, A/B/C concepts and the existing modular-magnet visual.
- Constraints: preserve node actions, workspace persistence, citations, deep links and honest `live/cache/stale/warning/error/degraded/blocked/offline` states. A discovered URL never becomes formal cultural knowledge automatically; historical market evidence never becomes live merely because a schedule exists. Do not alter cultural facts or imply production, compliance or commercial-artwork approval.
- Chosen direction: C2 **Tonal Focus Review**, approved by the user and implemented locally for desktop. Fixed tokens are shell `#E6E2DA`, command `#D9E1E8`, rail/Dock `#D7E1DC`, canvas `#E3E8EB`, Inspector `#E7DDD4`, node `#F0EEE9`, selected `#CBD9E6`, primary `#345C7D`, text `#20262C`, secondary text `#626970` and rule `#C4C8C7`; status colors are success `#637E6A`, warning `#B1844C`, danger `#9A6757` and neutral `#7B8086`.
- Approved composition: `.impeccable/mocks/tonal-focus-review.png`; SHA-256 `131cd5bedadd5be42888ace5d946ebaa2d4c3f3dc935e29393fd1127ebf7ffeb`. It is a non-literal reference for region proportions, tonal grouping and focus rhythm, not a data asset or a source for generated names, timestamps, thumbnails, counts or topology.
- Desktop structural signature: a 60px mist-blue command bar; below it a 72px gray-green rail and flexible mist-blue React Flow canvas; when open, a 210px evidence/asset/history Dock spans the bottom from the rail edge to the viewport; a 330px warm-clay Inspector overlays the right edge. The canvas remains the dominant work surface.
- Selection: light-stone nodes keep stable geometry. Selection changes only to `#CBD9E6` with a `#345C7D` border/handle and Inspector binding; it does not resize, move, lift or expand nodes.
- Dock behavior: Evidence, Asset and History share the 210px bottom slot, remain independently scrollable and keep real actions visible. Market history and its time boundary precede live controls. Dock closure restores the canvas row.
- Inspector behavior: the 330px panel is a reversible right overlay with a warm-clay root and light-stone fields/cards. It closes without retaining pointer/focus interception and does not mutate the selected node or API data.
- Direct manipulation: the empty canvas pans with primary-pointer drag; Shift-drag keeps box selection; wheel keeps zoom; dragging a node moves only that node. Every draggable evidence record also exposes a visible add-to-canvas button and keyboard path.
- Shared surfaces: Decision Studio uses shell + command header/footer + rail stage navigation + canvas panel + node fields. All nine detail routes, citation ledgers, ranking/opportunity/concept/poster/BOM surfaces and the collection console use the same C2 families without changing component logic.
- State grammar: success/healthy uses the success marker; cache/idle uses neutral; stale/warning/degraded/paused uses a warning outline; error/failed uses danger; blocked uses a danger outline plus an explicit reason. Text and shape remain present, so color never carries state alone.
- Continuous evidence: culture detail separates formal records/sources from pending candidates and exposes scheduler heartbeat, attempts, successes, partial failures and review history. Market detail puts 378 historical samples, date window and platform distribution before an expandable live-collection console. Polling or heartbeat failure invalidates stale online state; partial source failure is `degraded`; missing live switch/runtime/authorization is `blocked`.
- Dark exception: the existing culture relationship constellation keeps its functional `#070708` stage, SVG nodes and hit area. Search, filters, toolbar, legend, controls and evidence Inspector use C2 surfaces. The dark stage does not authorize a site-wide dark theme, decorative star field or grid.
- Forbidden treatments: large pure-white planes, gradients, mesh gradients, glass/backdrop blur, glow, neon, high-saturation chrome, decorative color, invented thumbnails and ordinary-card drop shadows.
- Typography / shape: retain the system/SF-like/Noto Sans SC UI stack and mono IDs. Use the established 4px spacing rhythm, 10–14px surface radii and 1px rule; pill geometry remains limited to short controls and status badges. Ordinary cards and Decision Studio have no shadow; only the desktop Inspector may keep a restrained shadow while it genuinely overlaps the canvas.
- Accessibility behavior: keep labelled Culture Graph, Workspace and Decision Studio semantics, visible keyboard focus, modal focus containment and trigger restoration. Desktop constellation search/selection/drag/wheel/keyboard paths and forced-colors roles remain covered. Axe and screenshots are regression evidence, not WCAG certification.
- Desktop validation: frontend unit tests 5/5; `desktop-chromium` 31/31 at 1440×960; typecheck, lint and Vinext production build pass. The final-fix wave left the two Task 5 desktop snapshots byte-identical.
- Responsive boundary: the user cancelled C2 mobile/tablet adaptation. Task 4’s responsive C2 changes and mobile test were fully reverted. Existing mobile behavior and two mobile snapshots remain in the repository, and the snapshots stayed byte-identical during Task 5, but no mobile project was run for final C2 acceptance; do not call mobile/tablet adapted or validated.
- Runtime boundary: current four-platform live collection remains blocked by the disabled live switch and missing authorization sessions. The scheduler is continuous only while one Tool API/container, persistent runtime volume, restart policy, network and required authorization remain available; it is not a distributed queue.
- Release boundary: C2 is local and desktop-only; the protected online instance remains 0.8.0. The product still stops at DesignPackage, factory quote/sample brief and concept poster, not production release, factory order, commercial artwork approval or manufacturing/compliance readiness.
