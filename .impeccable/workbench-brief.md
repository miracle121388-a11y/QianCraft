# Workbench surface brief

- Scope / mode: `/`, desktop-first web operating surface; Operate.
- Audience / job: cultural researchers, product strategists, designers and demo reviewers inspect evidence, change decisions, run nodes and continue a design chain without losing provenance.
- Primary action: run the current workflow or continue from the selected node.
- Proof / content: 22 cultural records, 378 bounded historical market samples, eight opportunities, nine node instances, ten relationships, Human Decision v2, A/B/C concepts and the existing modular-magnet visual.
- Constraints: preserve real HTTP data, node actions, workspace persistence, citations, deep links and honest live/cache/stale/warning states; mobile keeps detail and decision tasks usable. Do not imply four-platform live authorization or production readiness.
- Chosen direction: C2 — Tonal Focus Review. A 60px mist-blue command bar and 72px muted-sage tool rail frame a fog-blue node canvas. A contextual 210px evidence drawer uses the same sage family, while a 330px soft-clay Inspector overlaps from the right. Warm mineral surrounds the application; light-stone nodes and one low-saturation blue selected state create hierarchy without pure-white expanses, gradients, glass, glow or decorative color.
- Palette: shell `#E6E2DA`, command bar `#D9E1E8`, rail/evidence `#D7E1DC`, canvas `#E3E8EB`, Inspector `#E7DDD4`, nodes `#F0EEE9`, selected `#CBD9E6`, primary/focus `#345C7D`, text `#20262C`, secondary `#626970`, rules `#C4C8C7`; semantic status colors are restricted to muted olive `#637E6A`, ochre `#B1844C`, clay `#9A6757` and gray `#7B8086`.
- Memorable moment: selecting a node applies one deep desaturated blue keyline, rebinds the evidence drawer and Inspector with a restrained crossfade, and leaves node geometry and provenance paths stable.
- Approved comp: `.impeccable/mocks/tonal-focus-review.png`; sidecar `.impeccable/mocks/tonal-focus-review.json` records the user approval.
- Keep non-literal: do not reproduce invented node names, dates, people, thumbnails, labels or topology from the comp; use QianCraft's real nine nodes, ten relationships, data and existing product assets.
- Responsive behavior: keep canvas, evidence drawer and Inspector simultaneously legible at 1280px and above; below that, make the drawer and Inspector reversible overlays. At 760px and below, preserve page scrolling until the user explicitly operates a direct-manipulation canvas.
- Information discipline: keep every canvas node compact and geometrically stable; move summaries, fields and actions into the bound Inspector or dedicated detail page. Show one user-facing Chinese label per concept, keep status and summary singular, and progressively disclose run IDs, raw fields and methodology JSON.
