# Workbench surface brief

- Scope / mode: `/`, desktop-first web operating surface; Operate.
- Audience / job: cultural researchers, product strategists and designers inspect evidence, change decisions, run nodes and continue a design chain without losing provenance.
- Primary action: run the current workflow or continue from the selected node.
- Proof / content: 22 cultural records, 378 bounded market samples, eight opportunities, nine node instances, Human Decision v2, A/B/C concepts and the existing modular-magnet visual.
- Constraints: preserve real HTTP data, node actions, workspace persistence, citations, deep links and honest live/cache/stale/warning states; mobile keeps detail and decision tasks usable.
- Chosen direction: Creative Instrument Workbench with warm editorial chrome. A 56px parchment phase command bar and 64px warm-sand tool rail hold a dominant node canvas; evidence dock and inspector are contextual rather than permanent walls. Linen seams, 400/480 type weights, softly rounded containers and one indigo interaction/focus color combine the user's warm token set with the structural clarity of the later RICOUI reference, while indigo/rust cultural colors remain inside content.
- Memorable moment: selecting a node moves it one optical step forward, binds the inspector and leaves the provenance path visibly intact.
- Approved comp: `.impeccable/mocks/workbench-creative-instrument.png` (choice delegated by the user after rejecting both over-dense and showcase-minimal rounds).
- Keep non-literal: do not reproduce invented node names, dates, thumbnails or reference imagery from the comp; use QianCraft's real nodes, data and existing product asset.
- Responsive behavior: ship the evidence dock open on desktop for recognisable tool context; at 760px and below, collapse both peripheral panels, center the selected node and open docks/Inspector as reversible overlays.
